## 1. 폰트

| 용도 | 폰트 | 비고 |
|---|---|---|
| 한글 | **Noto Sans KR** (400/500/700) | 본문·부스명·게임명 전부 |
| 영문·숫자 | **Plus Jakarta Sans** (400/500/600/700) | 회사 영문명, 부스번호, UI |

`font-family: "Plus Jakarta Sans", "Noto Sans KR", "Apple SD Gothic Neo", system-ui, sans-serif`

글리프 단위로 폴백이 걸려서 영문은 Jakarta, 한글은 Noto가 자동으로 잡힙니다.

**제약**: 아티팩트 보안 정책상 외부 폰트는 `fonts.googleapis.com`에서만 불러올 수 있습니다. A2Z·프리텐다드·G마켓산스 등 Google Fonts에 없는 폰트는 넣을 수 없습니다.

**자간**: 한글 제목 `-0.015em`, 본문 `-0.01em`, 부스번호 `+0.02em`.

## 3. 부스 박스

- **테두리 없음.** 카테고리 배경 틴트 + 상단 강조 바(높이 2~4px, 카테고리 강조색)로만 구분
- 모서리 `rx: 5`
- 부스 간 간격 `2.2` 단위 (박스를 안쪽으로 깎아서 확보)
- 내용 순서 (위→아래): 부스번호(좌) · 국기(우) → 회사명 → 게임명
- **부스번호와 국기는 `h≥30 & w≥42`일 때만** 표시. 좁으면 카드에서만
- 글자는 박스 밖으로 못 나감 (`clipPath` 고정)

### 글자 크기 규칙

```
게임명  gfs = min(가용폭/게임명길이, (본문높이*0.62)/줄수, 12)    최소 3.3
회사명  nfs = min(가용폭/회사명길이, max(gfs*1.12, 4), 13)        최소 3.2
```

회사명과 게임명 차이는 **1.12배 이내**로 유지합니다. 회사명이 게임명을 압도하면 안 됩니다.
안 들어가면 회사명을 줄임표로 자릅니다. 부스번호를 이름 자리에 대신 넣지 않습니다.

## 5. 지도 구조

- 홀 1–8 / 홀 9–11 두 덩어리, 각각 흰 바닥 위에 배치
- 홀 경계는 점선, 홀 번호는 바깥쪽 상단
- 두 덩어리는 **2F 연결 통로**(보라 굵은 띠 + 점선 중심선)로 연결. 통로 위에 `2F 연결 통로 · 도보 5분`과 `10:00까지 9–11홀 → 1–8홀 이동 불가` 표기
- 입구는 빨간 점 + 홀 쪽으로 향하는 점선 진입선
- 9–11홀 구역(인디 / 물販 / e스포츠 / 하드웨어 / 스마트폰 / 코스프레 등)은 라운드 칩 라벨로 표시

## 6. 인터랙션

- 확대는 **SVG 크기 변경**으로 (CSS `transform: scale()` 금지 — 래스터화돼서 뭉개짐)
- 이동은 `transform: translate()`만
- 지도 영역 텍스트 선택 차단 (`user-select: none` + `pointerdown` 기본동작 차단)
- 터치 타겟 최소 36×36
- 세로/가로 전환 지원. 모바일은 세로 기본
