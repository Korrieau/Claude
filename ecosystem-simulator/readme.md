# 번영의 계보 — 생물·생태 시뮬레이터

형질 33개를 배분해 종 하나를 설계하고, 33종이 이미 자리 잡은 땅에 풀어놓습니다.
300년 뒤 동물 가운데 종합 번영 지수 1위가 되면 승리입니다.

브라우저에서 `index.html` 파일을 열면 바로 실행됩니다.
설치도, 인터넷 연결도, 외부 라이브러리도 필요 없습니다.

---

## 게임 흐름

**1. 설계** → 식성(초식·육식·잡식·분해자)을 고르고 형질 33개에 260포인트를 나눕니다.
상충하는 형질을 동시에 올리면 추가 비용이 붙습니다.

**2. 지역 선택** → 세계를 둘러보고 창시자 개체군을 풀어놓을 지역을 클릭합니다.
적합도 레이어가 어디가 살기 좋은지 보여줍니다. 좋은 땅에는 경쟁자도 많습니다.

**3. 관측** → 48×48 격자를 원으로 잘라낸 섬 위에서 시뮬레이션이 돌아갑니다. 1틱 = 한 계절, 4틱 = 1년.
지형·식생·기온·수분·오염·종 분포·적합도를 레이어로 전환해 봅니다.
지형 위에는 **내 종이 사는 범위가 제 색으로 덮여** 있습니다. 이게 300년에 걸쳐
넓어지는 걸 보는 게 이 게임입니다. 종 목록에서 다른 종을 누르면 그 종의 범위로 바뀝니다.

| 조작 | 하는 일 |
|---|---|
| 드래그 | 회전 |
| 휠 | **커서가 가리키는 곳으로** 확대. 물러날 때는 서서히 가운데로 |
| 우클릭(또는 Shift) 드래그 | 이동 |
| 방향키 · WASD | 이동 |
| Home | 가운데로 |

## 시간

| 속도 | 1년 |
|---|---|
| ×1 | 4초 |
| ×4 (기본) | 1초 |
| ×16 | 0.25초 |

처음엔 ×1이 1년 0.88초였습니다. 그러면 계절이 0.22초마다 바뀌고 기온 숫자가
초당 4~5번 널뛰어, 세계가 변하는 게 아니라 화면이 깜빡이는 것처럼 보였습니다.
진화 포인트도 1.3~7.5초마다 도착해서 결정이 아니라 잡일이 됐습니다.

고친 방법은 셋입니다.

- **1년을 4초로** 늘렸습니다 (×1 기준). 기본 속도는 ×4라 평소엔 1년 1초로 흐릅니다.
- **기온을 연 단위로 보여줍니다.** `17°C · 여름 26 / 겨울 6` — 계절 순간값을 그대로
  띄우던 게 깜빡임의 정체였습니다. 시뮬레이션은 그대로 두고 표시만 바꿨습니다.
- **판단이 필요한 순간에 자동으로 멈춥니다** — 진화 포인트 도착, 시대 시작,
  내 종이 최대치의 35% 아래로 급감. 끄고 켤 수 있습니다.

이 게임의 재미는 *환경을 읽고 → 내 종을 맞춰 진화시키고 → 번영하는 걸 보는 것*인데,
세 단계 다 시간이 필요합니다. 자동 정지가 있어야 진화가 흘러가는 숫자가 아니라 사건이 됩니다.

확대가 언제나 세계 한가운데로만 파고들면 가장자리를 가까이 볼 방법이 없습니다.
그래서 카메라가 바라보는 지점을 따로 두고, 휠을 굴리면 그 지점이 커서 쪽으로 끌려갑니다.
이동은 화면에서 끈 만큼 땅이 정확히 따라오게 맞춰 놓았습니다.

**4. 진화** → 몇 년마다 진화 포인트를 받아 형질을 1칸씩 조정합니다.
포인트가 오는 주기는 **세대 시간**이 정합니다. 쥐는 3년마다, 들소는 8년마다 옵니다.

진화 패널 맨 위에 **지금 내 종을 죽이고 있는 것**이 뜹니다 — 굶주림·포식 압력·더위·추위·과밀·사냥 실패.
그에 맞는 형질에는 `추천`, 방해가 되는 형질에는 `부담` 표가 붙고 목록 위로 올라옵니다.
이게 없으면 형질 33개짜리 목록은 그냥 표일 뿐이고, 진화가 판단이 아니라 찍기가 됩니다.

**5. 결과** → 최종 순위·번영 지수·최대 개체수·관측 기간·멸종한 동물 수를 카드로 먼저 보여주고,
그 아래에 전체 순위표, 300년 개체수 추이, 이번 판의 시나리오가 붙습니다.
멸종한 종은 0%을 늘어놓지 않고 사라진 해만 적습니다.

**종료 조건** → 아래 넷 중 하나로 끝납니다.

| 엔딩 | 조건 |
|---|---|
| 평형 | 10년 넘게 전체 개체수 변동이 6% 아래로 유지됨 |
| 300년 | 관측 기간 만료 |
| 계보의 끝 | 내 종 멸종 (배드) |
| 침묵의 땅 | 모든 동물 멸종 (배드) |

**자원** — 식물·부식물·토양은 모든 동물이 나눠 먹는 바탕입니다. 재생되지만 한정돼 있습니다.
식물은 스스로 움직이지 않고 경쟁 상대도 아니라서, 종 목록에서 빼고 자원 패널로 따로 봅니다.
식물량은 해마다 늘고 주는 추세가 함께 표시되고, '먹이 사정'은 동물들이 실제로 배가 찼는지를
개체수로 가중한 평균 만족도로 보여줍니다.

**승리 판정** — 개체수(로그) · 서식지 점유 · 바이오매스(로그) · 안정성을 각 25%씩 합산합니다.
네 항목을 똑같이 나눈 이유는 전략마다 이길 길을 하나씩 열어두기 위해서입니다.
다산형은 개체수로, K전략은 바이오매스와 안정성으로, 분해자는 서식지로 이깁니다.
식물은 개체수와 면적에서 언제나 압도하므로 생태계 기반으로 분리하고 동물끼리만 순위를 매깁니다.

## 적용한 생태 이론

| 이론 | 게임에서 하는 일 |
|---|---|
| 로지스틱 성장 · 환경수용력 | 자원이 정한 상한에 부딪히면 번식이 멈춤 |
| r / K 선택 | 많이 낳고 방치할지, 적게 낳고 키울지 — 새끼 생존율이 정반대로 움직임 |
| Holling III형 기능 반응 | 포식자는 흔한 먹이에 집중. 희귀해진 종은 오히려 덜 잡힘 |
| 최적 채이 이론 | 포식자마다 수지가 맞는 먹이 크기가 있음 |
| 로트카–볼테라 종간 경쟁 | 지위가 겹치는 종의 개체수가 내 환경수용력을 갉아먹음 |
| 경쟁 배타 원리 · 지위 분화 | 식성·몸집·서식지·활동 시간이 다 겹치면 한쪽이 밀려남 |
| 알리 효과 | 너무 흩어지면 짝을 못 찾음. 멸종에는 임계점이 있음 |
| 희석 효과 | 무리가 클수록 개체당 잡아먹힐 확률이 낮아짐 |
| 생태 천이 · 중간교란 가설 | 교란된 땅은 개척종, 안정된 땅은 극상종 |
| 베르그만 법칙 | 큰 몸은 열을 덜 잃음. 대형종은 추운 곳에 유리 |
| 자연선택 (브리더 방정식 R = h²·S) | 모든 종이 자기를 죽이는 요인에 맞춰 형질을 바꿈. 하나 오르면 하나 내려감 |
| 세대 시간과 진화 속도 | 진화의 시계는 '년'이 아니라 '세대' |
| 유전적 부동 · 병목 효과 | 개체수가 적으면 선택이 헛돌고 형질이 제멋대로 흔들림 |
| 붉은 여왕 가설 | 먹이가 방어를 올리면 포식자는 사냥을 올림 |

## 세계

- **지형** — 48×48 정사각 격자(원 안쪽 약 1,690칸)를 평면에 펴고 바깥 테두리만 원으로
  잘라냈습니다. 유리 돔이 그 위를 덮고 카메라는 돔 안쪽에서 봅니다.
  처음엔 격자를 극좌표로 원반에 폈는데, 그러면 바깥쪽 칸이 넓고 얇은 띠로, 중심 칸이
  쐐기로 늘어나 부자연스러웠습니다. 정사각 격자를 원으로 잘라내니 칸은 어디서나 같은
  모양이면서 세계는 둥글게 보입니다.
- **높이** — 고도를 9단계로 끊습니다. 칸마다 제각각 높으면 지형이 자잘하게 들쭉날쭉해집니다.
  같은 단계끼리는 평평하게 이어지고 단계가 바뀌는 곳에만 계단이 생깁니다.
- **바다와 해안선** — 육지와 바다는 평면 좌표 노이즈로 나눕니다. 바다가 꼭 바깥 고리에
  있지는 않아서 내해가 생기기도 하고 대륙이 한쪽으로 치우치기도 합니다.
  바다에 맞닿은 낮은 땅은 해변이 되고, 앞바다에는 섬이 몇 개 뜹니다.
- **산맥** — 능선을 길게 이어 산맥으로 만듭니다. 능선은 뾰족하고 기슭은 완만합니다.
- **강** — 산꼭대기에서 시작해 가장 낮은 이웃으로 흘러내립니다. 아래로 갈수록 물이 모여
  강폭이 넓어지고, 바다에 닿으면 하구에 삼각주가 생깁니다. 내려갈 곳이 없으면
  그 자리가 호수가 됩니다. 물길 양옆은 축축한 강가가 됩니다.
- **지역 생성** — 사막·극지·정글·습지는 매 판 반드시 하나씩, 나머지는 평원·숲·초원으로
  채워집니다. 화산은 원뿔로 솟고 가운데가 분화구로 꺼집니다.
- **도시** — 사람이 정착한 뒤 도시가 들어서고 해마다 가장자리로 번져나갑니다.
  땅이 콘크리트로 덮여 토양과 수분이 마르고 오염이 쌓입니다. 지능과 오염 내성이
  높은 종만 도시에서 버팁니다. 도시 자리를 고를 때 원 밖 칸을 빼지 않아
  세계 바깥에 도시가 서고 로그만 뜨던 버그가 있었습니다.
- **지형 종류** — 호수 · 습지 · 초원 · 숲 · 사막 · 산지 · 설원 · 정글 · 화산 · 도시 · 바다 · 해변 · 강
- **시나리오** — 판마다 하나가 뽑혀 300년 전체의 줄거리가 됩니다. 스쳐 지나가는
  사건이 아니라 이 판의 주제입니다. 세력이 시간에 따라 오르내립니다.

  | 단계 | 기간 | 세력 |
  |---|---|---|
  | 전조 | 1~60년 | 0 → 0.25 |
  | 심화 | 60~150년 | 0.25 → 0.65 |
  | 절정 | 150~234년 | 0.65 → 1.0 |
  | 여파 | 234~300년 | 되돌아감 (되돌릴 수 없는 것은 유지) |

  기온·강수·광량은 세력에 비례해 흔들리고, 땅이 바뀌는 빈도도 세력을 따라갑니다.
  처음부터 최대로 때리면 대비할 틈이 없습니다.

  | 시나리오 | 땅에 생기는 일 | 하늘 |
  |---|---|---|
  | 빙하기 | 추운 칸부터 설원으로 덮임 | 창백한 파랑 |
  | 급격한 온난화 | 설원이 녹아 초원으로 | 뜨거운 아지랑이 |
  | 운석 충돌 | 충돌 지점 반경이 초토화 | 먼지가 해를 가린 잿빛 |
  | 화산 겨울 | 산지가 터져 화산이 되고 재가 쌓임 | 화산재 |
  | 대가뭄 | 습지·초원이 사막으로 | 누런 흙먼지 |
  | 대녹화 | 사막이 초원으로, 초원이 숲으로 | 맑고 푸름 |
  | 산성비 | 오염이 쌓이고 토양이 깎임 | 매연 섞인 회록색 |
  | 방사능 유출 | 오염이 번지고 돌연변이 급증 | 보랏빛 |
  | 해수면 상승 | 해안 저지대가 바다로 잠김 | 무거운 회청색 |
  | 인간의 세기 | 도시와 농지가 대륙을 덮음 | 매연이 옅게 낀 하늘 |

- **징후** — 무엇이 오는지는 알려주지 않습니다. 전조기에 10~19년마다 조짐만 흘립니다.
  "겨울이 예년보다 조금 길어졌습니다" → "여름에도 서리가 내린 날이 있었습니다".
  세력이 0.25를 넘으면 그제야 이름이 드러납니다. 읽고 알아채서 미리 맞춰 두는 것이
  이 게임의 핵심입니다.
- **사람** — 인간 시나리오(인간의 세기·방사능·산성비·해수면 상승)가 뽑힌 판에만
  42년경 등장합니다. 아니면 사람이 닿지 않은 땅으로 300년이 갑니다.
  정착한 뒤로는 사건이 아니라 해마다 번집니다 — 300년 기준 도시 약 200칸(육지의 12%),
  농지 300~520칸. 100년 25칸 → 200년 100칸 → 300년 200칸.
- **작은 사건** — 시나리오가 줄기라면 이쪽은 곁가지입니다. 가뭄, 폭우·범람, 폭염,
  한파, 산불, 전염병, 풍년, 국지 교란, 지각 변동. 사람이 있는 판에서는 폐수, 살충제,
  남획, 도로, 외래종, 보호구역 지정도 섞입니다.
- **토착종 구성** — 매 판 달라집니다. 기능군마다 최소 수는 보장해 먹이사슬이 끊기지 않게 하고,
  나머지는 뽑기로 넣거나 뺍니다. 같은 종이라도 형질을 조금씩 흔들어 판마다 다르게 만듭니다.

## 난이도

밸런스는 헤드리스 자동 플레이로 검증했습니다. 프리셋 6종을 각각 10회씩,
합쳐서 **60회**를 돌린 결과입니다. 자동 플레이어는 진화 포인트를 받는 대로
선택압에 맞는 형질 하나에 몰아 쓰는 수준이라, 사람이 하면 이보다 잘 나옵니다.

- 프리셋 6종 × 10회: **생존 58/60 (97%), 우승 2/60**
- 무작위 빌드 48개: **생존 34/48 (71%)**, 그중 8개가 1위 달성
- 식성별 생존률 — 잡식 79%, 초식 79%, 분해자 64%, **육식 43%** (가장 어려움)

살아남기는 어렵지 않지만 1위는 어렵습니다. 육식 최상위 포식자는 가장 위험한 선택입니다.

**급락의 원인을 찾은 과정** — 개체수가 한 해에 반토막 나는데 화면에는 아무 이유도
안 보인다는 문제가 있었습니다. 감쇠 후보 4종을 288판 돌려 비교했지만 개선이 미미했고
(연 변동 11.0% → 9.2%) 생존률만 깎였습니다. 방향이 틀렸던 겁니다.
그래서 사망 원인을 항목별로 기록하게 만들고 급락 연도와 평시를 비교했더니 답이 나왔습니다 —
**급락 연도 사망의 46%가 전염병**이었고 평시에는 6%였습니다. 전염병이 돌면 사망률이
32배로 뛰는 절벽이 있었습니다. 이 배율을 손보자 급락이 59건에서 11건으로 줄었고,
남은 급락은 굶주림과 포식이라는 눈에 보이는 원인이 됐습니다.
사망 원인 기록은 그대로 두었습니다 — 무엇이 죽였는지는 플레이어도 알아야 합니다.

**표본 수에 대한 메모** — 프리셋당 4회(합계 24회)로는 튜닝을 할 수 없습니다.
같은 설정을 반복해서 돌려도 21~24 사이로 흔들려서, 설정을 바꿔서 생긴 차이인지
운인지 구분이 안 됩니다. 조절값을 비교하려면 프리셋당 최소 10회는 돌려야 합니다.

## 기술 메모

- 단일 HTML 파일. 외부 의존성 없음.
- 3D는 순수 WebGL로 직접 구현했습니다. Three.js 같은 라이브러리를 쓰지 않아
  CDN 장애 영향을 받지 않고, WebGL을 못 쓰는 환경에서는 2D 지도로 자동 대체됩니다.
- 아트 방향은 밝은 저폴리. 지형은 칸마다 제 높이의 평평한 면을 놓고, 옆 칸과 높이가
  다르면 그 사이에 절벽 벽면을 세우는 계단식입니다. 꼭짓점 높이를 평균 내면 이어지긴
  하지만 죄다 둥글어져 슬라임처럼 보입니다.
- 지형마다 나무·풀·바위·선인장·갈대·침엽수·건물을 실제로 세웁니다. 시뮬레이션과 무관한
  배경이라 한 번 만들어 두고 씁니다 (사람이 땅을 바꾸면 다시 만듭니다). 생물은 상자와 기둥으로만 짠 장난감 모델이고,
  GPU 인스턴싱으로 매 프레임 형질대로 움직입니다 — 이동성이 높으면 넓게 돌아다니고
  순발력이 높으면 빠르게, 식물은 제자리에서 흔들리기만 합니다.
- 화면은 세계가 꽉 차고 HUD가 그 위에 떠 있는 구성입니다. 카타마리 다마시 계열의
  게임 HUD를 참고했습니다 — 꽃잎을 겹친 배지에 개체수를 얹고, 흰 글씨에 두꺼운
  외곽선을 두르고, 계절은 사분면 시계로, 최근 사건은 동그란 아이콘과 이름표로 보여줍니다.
- **화면에 보이는 것은 밀도 얼룩이 아니라 개체입니다.** 한 마리 한 마리가 계속
  살아 있으면서 걸어다니고, 어미 옆에서 태어나 자라고, 그 자리에서 오그라들어 죽습니다.
  처음에는 매 틱마다 '밀도가 문턱을 넘은 칸'을 새로 골라 찍었습니다. 그래서 아무것도
  이어지지 않았고, 뿅 나타났다 뿅 사라지는 것으로만 보였습니다. 시뮬레이션을 개체 단위로
  돌리는 건 아니고, 개체 수가 개체군을 따라갑니다 — 개체군이 늘면 새끼가 태어나고
  줄면 죽습니다. 태어나고 죽는 속도는 초당 몇 마리로 묶어 두었습니다. 한 프레임에
  몰아서 처리하면 결국 예전처럼 우르르 나타났다 우르르 사라지는 것으로 보입니다.
  걸음걸이는 형질이 정합니다 — 이동성이 높으면 멀리, 순발력이 높으면 빠르게,
  식물은 제자리에서 흔들리기만 합니다.
- 개체 수는 개체수의 로그에 비례합니다. 그대로 쓰면 곰팡이 10만 마리가 화면을 덮고
  늑대 30마리는 보이지도 않습니다.
- 생태 조절값은 소스의 `TUNE` 객체 한곳에 모여 있어 밸런스 조정이 쉽습니다.
- 차트 팔레트는 색각 이상 대비를 자동 검증한 뒤 확정했습니다.
