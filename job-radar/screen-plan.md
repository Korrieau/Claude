## 1. 전체 구조

하단 탭 바로 4개 탭 이동. 각 탭 맨 위에 얇은 큰 영문 제목(JOBS, SPEC 등)과 번호(01 / 04).

| 번호 | 탭 | 하는 일 |
|---|---|---|
| 01 | 공고 | 공고 목록, 국가 필터, 적합도 순 정렬, 공고 상세 |
| 02 | 기업 | 회사별 정보 모음 (위치, 규모, 대표작, 근무 방식, 복지) |
| 03 | 내 스펙 | 내 이력 정리, 스탯 표, 이력 붙여넣기 |
| 04 | 테스트 신청 | CBT·베타테스트 모집 목록 (넘기는 카드) |

상세 화면: 탭 바 대신 "원문 보기 / 회사 지원 페이지" 버튼 바.

**지원 상태 관리**: 공고마다 관심 → 지원함 → 결과 대기 → 종료. 목록 카드와 요약 칸(지원함 수)에 표시.

## 2. 화면별 내용

### 01 공고 — 목록
- 요약 3칸: 새 공고 수 / 7일 안에 마감 / 지원함 수
- 국가 필터 탭: 전체 · 한국 · 일본 · 중국 · 미국 (노란 평행사변형이 이동)
- 공고 카드: 회사 이름 블록 + 적합도 큰 숫자 + 경고 표시("필수 N개 부족" 또는 "확인 필요 N개") → 날짜, 태그(국가·직무·마감), 제목, 2줄 요약
- 정렬: 적합도 높은 순 (기본) / 마감 빠른 순

### 01 공고 — 상세
- A. 적합도 근거: 공고 조건 하나씩 "충족 / 일부 / 부족 / 확인 필요" 표시 + 내 이력 근거
- B. 지원에 필요한 스탯: 부족한 조건을 무엇으로 채울지
- C. 공고 요약: 담당 업무, 지원 자격, 우대 사항, 근무 조건 (외국어 공고는 한글 번역 + 원문 언어 표시)
- D. 기업 정보: 위치, 규모, 대표작, 근무 방식, 복지 + 출처

### 02 기업
- 회사 카드 목록: 공고 상세의 D와 같은 항목
- 평가(평점)는 일단 제외
- 출처와 확인 날짜를 항상 표시. 출처끼리 숫자가 다르면 둘 다 표시 (예: 직원 수)

### 03 내 스펙 (게임 설정 화면 방식)
- 그룹별 줄: LANGUAGE(영어 원어민, 한국어 원어민, 일본어·중국어 못 함·학습 희망), CONDITIONS(해외 출장·근무, 희망 근무지), CAREER
- 값을 바꾸면 모든 공고의 적합도가 다시 계산됨
- 비어 있는 항목은 "미입력"으로 표시하고, 몇 개 공고의 점수에 영향을 주는지 보여줌
- 이력 추가: 글을 붙여넣으면 항목별로 정리

### 04 테스트 신청
- 넘기는 카드 (게임 소개 섹션 모양): 게임명, 회사, 플랫폼, 모집 기간, 신청 링크, 남은 날짜

## 3. 적합도 계산 방식 (제안)

| 구분 | 점수 |
|---|---|
| 필수 조건 | 개수에 맞춰 나눔 (합계 60점) |
| 우대 조건 | 개수에 맞춰 나눔 (합계 30점) |
| 경력 조건 | 10점 |

- 충족 = 만점, 일부 = 절반, 부족·확인 필요 = 0점
- "확인 필요" 항목이 모두 충족됐을 때의 최대 점수를 같이 표시
- 필수 조건 중 결정적인 조건(예: 언어)은 "핵심 변수"로 따로 표시

## 4. 샘플 공고: 에피드게임즈 [트릭컬 리바이브] 글로벌 사업PM

- 원문: https://www.gamejob.co.kr/Recruit/GI_Read/View?GI_No=286405
- 적합도 **45 / 100** (해외 출장 확인 시 최대 65). 필수 조건 1개 부족 → 지금은 지원 어려움
- 부족한 조건: **일본어 또는 중국어 원어민 수준**. 영어 원어민은 이 공고 조건이 아님
- 공고 본문이 이미지로만 되어 있어, 이미지를 직접 읽고 정리함

## 5. 데이터 저장 방식 (결정: 자동화 쉽게)

- 공고·기업·내 스펙·테스트 신청을 **표 형태 데이터 파일**로 관리. 열 이름을 나중에 만들 구글 시트와 똑같이 맞춤
- 지금(B 단계): Claude가 검색해서 데이터 파일을 채움 → 앱이 그 파일을 읽어 화면에 표시
- 나중(A 단계): n8n이 같은 열 구조로 구글 시트에 쓰고, 앱은 시트를 읽음. 앱 화면은 바꿀 필요 없음
- 지원 상태처럼 내가 앱에서 바꾸는 값은 우선 휴대폰에 저장하고, 내보내기 버튼으로 시트에 붙여넣을 수 있게 함 (A 단계에서 자동 연동으로 교체)

## 6. 내 스펙 변경 반영
