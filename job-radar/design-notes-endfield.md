## 엔드필드 사이트 특징 → 앱 적용
| 사이트 | 앱 |
|---|---|
| 연회색 바탕 `#F2F2F2` + 흰 패널, 3px 테두리, 모서리 거의 없음 | 바탕 `#ECEEF1`, 흰 패널 3px `#DDE1E6` 테두리, radius 2px |
| 검정 글자 `#191919` | 같음 |
| 형광 노랑 `#FFFA00` 세로 띠 + 회전 글자 | **파랑 `#1F5BFF`** 세로 띠 + 회전 글자 (공고 종류마다 파랑 톤 변화) |
| 와이드 영문 글꼴 (Novecento Sans Wide) | 무료 대체: **Archivo 125% 폭** |
| `[ Kay ]`, `// 01`, 아주 작은 기술 라벨, ↘ 박스 | 회사명 `[ ]`, 섹션 `// 01`, JetBrains Mono 라벨, ↘ 박스 |
| 마젠타·노랑·초록 3색 바 | 파랑·하늘·검정 3색 바 |
| 검정 버튼 + 노랑 세로 막대 (`| More Intel`) | 검정 버튼 + 파랑 세로 막대 (`| CSV`, `| 원문 보기`) |
| 흰 원형 화살표 버튼 (그림자) | 내 스펙 선택기 ‹ › |
| 사선 빗금 무늬 (-45°) | 상세 상단·테스트 카드의 어두운 패널 |
| 눈금선, `1 / 5` 페이지 표시 | 점수 막대(눈금 배경), `03 / 30` 건수 표시 |

## 바꾸지 않은 것
- 공식 로고·캐릭터·이미지·전용 글꼴 파일은 쓰지 않음
- 기능(점수 계산, 데이터 저장, 상태 관리, CSV)은 그대로

## v5 추가: 하위 페이지·로딩·움직임 반영
| 엔드필드 | 앱 |
|---|---|
| 로딩: 어두운 화면 `#141414` + 가운데 로고 + 왼쪽 아래 % 숫자 + 진행 막대 `scaleX` + 노란 화면 번쩍임 | 같은 구성, 데이터 6종을 받을 때마다 % 증가, 파란 번쩍임으로 전환 |
| 섹션 등장: 깜빡임 `0→.5→0→.5→0→1` (flashing) | 화면 전환 때 머리·카드가 순서대로 깜빡이며 등장 |
| 메뉴: 오른쪽에서 밀려오는 흰 전체 화면, 옅은 사선 격자, 회색 줄(아이콘 칸 │ 이름 ›), 선택 줄은 강조색 | 같은 구성, 선택 줄 파랑 + CSV 내보내기 |
| 뉴스 페이지 머리: 색 띠 + `News:` + 작은 기술 문구 + 오른쪽 그림 | 파란 띠 + `Jobs:` + 좌표 문구 + 오른쪽 레이더(회전) |
| 텍스트 탭(세로선 구분, 선택 칸 회색 + ›) | 국가 탭 |
| 회색 알약 페이지 표시 + 흰 원형 화살표 | 홈 "주요 소식" 넘기기 |
| 아래로 움직이는 스크롤 힌트 화살표 | 홈 첫 화면 ↓ |
| 사선 격자 배경 | 전체 바탕 |
| 기사 소제목 `▼//` | 공고 요약 소제목 |
