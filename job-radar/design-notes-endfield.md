## 엔드필드 사이트 특징 → 앱 적용
| 사이트 | 앱 |
|---|---|
| 연회색 바탕 `#F2F2F2` + 흰 패널, 3px 테두리, 모서리 거의 없음 | 바탕 `#ECEEF1`, 흰 패널 3px `#DDE1E6` 테두리, radius 2px |
| 검정 글자 `#191919` | 같음 |
| 형광 노랑 `#FFFA00` 세로 띠 + 회전 글자 | **파랑 `#1F5BFF`** 세로 띠 + 회전 글자 (공고 종류마다 파랑 톤 변화) |
| 와이드 영문 글꼴 (Novecento Sans Wide) | 무료 대체: **Archivo 125% 폭** |
| `[ Kay ]`, `// 01`, 아주 작은 기술 라벨, ↘ 박스 | 회사명 `[ ]`, 섹션 `// 01`, JetBrains Mono 라벨, ↘ 박스 |
| 마젠타·노랑·초록 3색 바 | 파랑·하늘·검정 3색 바 |
| 검정 버튼 + 노랑 세로 막대 (`| More Intel`) | 검정 버튼 + 파랑 세로 막대 (`| CSV`, `| 원문 보기`) |
| 흰 원형 화살표 버튼 (그림자) | 내 스펙 선택기 ‹ › |
| 사선 빗금 무늬 (-45°) | 상세 상단·테스트 카드의 어두운 패널 |
| 눈금선, `1 / 5` 페이지 표시 | 점수 막대(눈금 배경), `03 / 30` 건수 표시 |

## 바꾸지 않은 것
- 공식 로고·캐릭터·이미지·전용 글꼴 파일은 쓰지 않음
- 기능(점수 계산, 데이터 저장, 상태 관리, CSV)은 그대로
