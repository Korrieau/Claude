## 5. 화면 구조 (메인)

위에서 아래로:

1. **상단 바 (고정)**: 검정, 높이 57px. 왼쪽 로고, 오른쪽 "DOWNLOAD NOW" 알약 버튼(흰 테두리) + 원형 음악 버튼
2. **메뉴 버튼 (고정)**: 상단 바 바로 아래 오른쪽에 떠 있는 정사각형 버튼 (검정 바탕, 흰 테두리, 줄 3개)
3. **01 메인 그림**: 사선으로 잘린 큰 그림, 왼쪽에 세로 글씨, 오른쪽에 재생·연령 버튼
4. **02 Characters**: 큰 캐릭터 그림 + 이름·소속, 아래 썸네일 줄(사선 모양) + 좌우 화살표, "View More"
5. **03 Videos**: 불규칙한 모양으로 잘린 영상 배너
6. **04 News & Info**: 왼쪽 라벨 + 오른쪽 뉴스 배너 1개 + "View More"
7. **05 Background**: 세계관 (job-radar에선 사용 안 함)
8. **06 Game Features (게임 소개)**: 넘기는 그림 슬라이드 + 아래 검정 띠에 라임색 제목 오른쪽 정렬 ("Dual Identities, A Singular Adventure") + 아주 작은 설명
9. **푸터**: 검정. SNS 아이콘 줄 → 언어 선택(알약) → 로고 → 링크 → 등급 표시 → 저작권
10. **하단 고정 바**: 반투명 검정 + 라임 버튼. 화살표로 펼치기/접기

**섹션 라벨 규칙:** 모든 섹션 왼쪽(또는 오른쪽) 위에 라임색 사선 블록 + "섹션 이름 + 두 자리 번호". 이 사이트에서 가장 눈에 띄는 요소.

## 6. 부품 모양

### 버튼
- **기본 (View More)**: 검정 바탕, 회색(`#767678`) 두꺼운 테두리(약 3~4px), 완전 둥근 알약, 흰 글자 + 오른쪽 화살표 `>`
- **주요 (Log in, 사전등록)**: 라임 바탕 `#D8FA00`, 검정 글자, 알약 또는 모서리 약간 둥근 사각형(radius 0.1rem)
- **상단 다운로드**: 검정 바탕, 흰 테두리 알약, Impact 대문자
- **TOP 버튼**: 흰 바탕 둥근 사각형, 위 화살표 원 아이콘 + "TOP"

### 카드 (뉴스)
- 이미지: **오른쪽 위와 왼쪽 아래 모서리만 둥글게** (`border-radius: 0 .55rem`). 나머지 두 모서리는 각짐 → 핵심 특징
- 이미지 아래: 날짜(Impact) + 태그 → 제목(굵게, 1줄에서 자름) → 요약(회색, 2줄에서 자름)
- 카드 테두리·그림자 없음. 바탕색 위에 바로 놓임

### 태그
- 검정 바탕 + 연한 라임 글자, 굵기 700, 아주 작음
- **왼쪽만 둥근 모양** (`border-radius: .14rem 0 0 .14rem`), 오른쪽은 사선 또는 각짐

### 탭 (뉴스 분류)
- 진한 회색 알약 바 안에 4개 탭 (Latest / News / Notices / Events)
- 선택된 탭: **흰색 평행사변형(기울어진 사각형)** 이 뒤로 미끄러져 옴, 글자는 검정
- 비선택 탭: 흰 글자

### 메뉴 (열린 화면)
- 위에서 내려오는 진한 패널 `#1F1F1F`, 아래쪽 모서리만 둥금
- 항목: 가운데 정렬, 알약 모양. 선택된 항목만 `#323232` 바탕 + 흰 글자, 나머지는 회색 글자
- 맨 아래: 화면 폭 가득 라임 알약 버튼 (Log in)
- 패널 아래 나머지 화면: 62% 검정 덮개
- 닫기 버튼: 오른쪽 위 둥근 사각형 회색 `×`

### 장식
- **필름 띠**: 검정 띠에 흰 사각형 구멍 줄. 섹션 사이 경계에 사선으로 배치
- **사선 면**: 흰색·회색 면을 비스듬히 잘라 겹침
- **줄무늬 패턴**: 진한 부분에 얇은 사선 줄무늬(카본 무늬)
- **큰 워터마크 글자**: 페이지 제목을 연회색 Impact 기울임체로 크게 깔기
- **기울이기**: 캐릭터 썸네일 등에 약 25° 기울임 (`skewX`)

## 7. 움직임 (애니메이션)

| 이름 | 값 | 쓰이는 곳 |
|---|---|---|
| 기본 전환 | `all 0.3s cubic-bezier(0.215, 0.61, 0.355, 1)` | 대부분의 요소 (약 200개). 빨리 시작해서 부드럽게 멈춤 |
| 느린 전환 | 같은 곡선, 0.5s | 슬라이드 이동, 큰 요소 |
| 카드 반응 | `all 0.5s ease` + 밑줄이 왼쪽에서 오른쪽으로 펼쳐짐 (`scaleX 0→1`) | 뉴스 카드 누를 때/마우스 올릴 때 |
| 메뉴 항목 반응 | 흰 바탕 + 검정 글자 + 1.12배 확대 | 메뉴 선택 |
| 두근거림 (heartbeat) | 0.8초 반복, 1 → 1.1 → 1 → 1.1 → 1배 | 아래로 스크롤 화살표 |
| 흔들림 (tada) | 1.1배 커지며 좌우로 3°씩 흔들림 | 눈길을 끌어야 하는 버튼 |
| 아래에서 올라오기 (slideToTop) | 아래 100% + 투명 → 제자리 + 불투명 | 섹션 등장 |
| 글자 흐름 (wordsLoop) | 글자가 옆으로 계속 흘러감 | 띠 장식 문구 |
| 좌우 넘기기 | 손가락으로 밀어서 넘김 (swiper) | 캐릭터, 영상, 게임 소개 |
| 탭 이동 | 흰 평행사변형이 선택한 탭으로 미끄러짐 | 뉴스 탭 |
| 하단 바 펼침 | 높이 0.25초, 화살표 180° 회전 | 하단 고정 바 |
| 사라지기/나타나기 | `opacity 0.2~0.3s ease` | 팝업, 이미지 |

**규칙:** 0.2~0.5초 안에 끝남. 튕기는 움직임 없음. 계속 반복되는 건 화살표와 흐르는 글자뿐.

## 9. 변경 (v2): 키 컬러 푸른색 + 모바일 앱 방식

젠존제 구조는 유지하고, 색과 글자를 **호시마치 스이세이 공식 사이트**(https://hoshimachi-suisei.jp/)에서 가져와 차별화.

### 스이세이 사이트에서 가져온 것
| 항목 | 값 |
|---|---|
| 키 컬러 (파랑) | `#003CFF` |
| 강조 (노랑) | `#F5FF14` (파랑 위 글자, 선택 표시) |
| 바탕 | `#CDDEE5` (연한 청회색), 보조 `#DDECF1` |
| 선 | `#ADCBD7` 1px. 화면 가운데 세로 그리드 선 |
| 영문 글자 | 얇고 넓은 자간 (원본 Avantt → 무료 대체 **Inter** 200~500) |
| 큰 제목 | 아주 얇은 굵기로 크게 (TOPICS, DISCOGRAPHY 방식) → JOBS, SPEC |
| 메뉴 블록 | 오른쪽 위 정사각형 파란 블록 + 노란 글자 |
| 움직임 | `0.4s cubic-bezier(.27,.76,0,1)`, 흐르는 글자 띠(marquee), 깜빡임(flicker) |

### 젠존제에서 유지한 것
- 한쪽 모서리만 둥근 카드 (`border-radius: 0 22px 0 22px`)
- 왼쪽만 둥근 태그, 평행사변형 탭 슬라이더
- 뉴스 목록 카드 구조: 이미지 영역 → 날짜+태그 → 제목 → 2줄 요약
- 뉴스 상세 구조: 가운데 정렬 굵은 제목 → 경로 알약 바(회사 > 직무 · 날짜) → 본문 소제목
- 하단 고정 버튼 바

### 모바일 앱 방식으로 바꾼 것
- 떠 있는 햄버거 메뉴 → **하단 탭 바** (공고 / 기업 / 내 스펙 / 테스트)
- 상단 바 56px 고정, 상세 화면은 "‹ 목록" 뒤로 가기 + 저장 버튼
- 상세 화면은 탭 바 대신 버튼 바 (원문 보기 / 회사 지원 페이지)
- **내 스펙 = 게임 설정 화면 방식**: 그룹 제목(LANGUAGE, CONDITIONS, CAREER) + 한 줄씩 "‹ 값 ›" 선택기와 켜기/끄기 스위치

> 참고: 젠존제 웹사이트에는 설정 페이지가 없어서, 설정 화면 방식은 게임 안 설정 메뉴의 일반적인 형태(그룹 + 줄 + 값 선택기)를 따랐음. 실제 게임 화면 캡처를 주시면 더 가깝게 맞출 수 있음.
