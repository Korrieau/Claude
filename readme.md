# PULSE

모바일 브라우저용 실시간 웨이브 생존 게임. 제작 진행 중.

## 현재 단계: 아트 스타일 비교

`art-style-test.html` — 같은 전투 장면을 3가지 스타일로 렌더한 비교 페이지.
파일 하나만 열면 되고, 설치나 빌드가 필요 없다.

### 보는 법
1. 파일을 브라우저로 연다 (폰에서 보려면 파일을 폰으로 옮기거나 깃허브 페이지로 연다).
2. 하단 A / B / C 버튼으로 스타일을 바꾼다.
3. 화면을 손가락으로 끌면 캐릭터가 따라온다. 공격은 자동.
4. "레벨업 카드 UI 보기" 버튼으로 강화 선택 화면을 확인한다.

### 3가지 스타일
| | 컨셉 | 특징 |
|---|---|---|
| A | ENDFIELD DARK | 차콜 바탕, 오렌지 강조. 셀 셰이딩 + 각진 형태 + 기술 문서형 HUD |
| B | ENDFIELD LIGHT | 콘크리트 바탕, 진한 잉크선. 형태 대비가 가장 또렷함 |
| C | NEON VECTOR | 발광 선과 잔상. 화려하지만 톤이 가벼움 |

세 스타일 모두 같은 시뮬레이션을 공유한다. 팔레트는 스타일당 색 6개로 고정.
이미지 에셋을 쓰지 않고 도형과 색 규칙만으로 그린다.

## 게임 설계 (확정분)

- 세로 화면, 한 손가락 드래그로만 조작. 공격은 전부 자동.
- 한 판 300초. 60초마다 엘리트, 240초부터 보스.
- 적 4종: 추적형 / 돌진형 / 원거리형 / 분열형.
- 무기 4종(펄스·볼트·오브·체인) 중 최대 3개 장착.
- 패시브 6종: 이동속도, 공격속도, 투사체 수, 크기·사거리, 흡혈, 획득 범위.
- 무기 최대 레벨 + 특정 패시브 조건을 만족하면 무기가 진화한다. 빌드가 갈리는 지점.
- 레벨업 시 정지 후 카드 3장 중 1택.
