# PULSE

모바일 브라우저에서 도는 실시간 웨이브 생존 게임. 한 판 5분.

`index.html` 하나만 열면 됩니다. 설치, 빌드, 인터넷 연결 모두 필요 없습니다.

## 어떻게 하는 게임인가

- **조작은 드래그 하나.** 화면 아무 곳이나 손가락으로 끌면 캐릭터가 따라옵니다. 버튼 없음.
- **공격은 전부 자동.** 유저가 하는 판단은 "어디에 서 있을까"와 "무엇을 강화할까" 둘뿐입니다.
- **목표는 5분 생존 + 보스 처치.** 남은 시간 60초에 보스가 나오고, 시간 안에 못 잡으면 패배합니다.

## 한 판의 흐름

| 구간 | 내용 |
|---|---|
| 0~60초 | 적이 드문드문. 무기 하나로 버티며 레벨을 올립니다 |
| 60 / 120 / 180 / 225초 | 엘리트 등장. 노란색이고 체력바가 붙습니다 |
| ~240초 | 적 밀도와 체력이 계속 상승. 화면이 채워집니다 |
| 240~300초 | 보스전. 일반 적은 확 줄지만 보스가 체력 절반 아래로 가면 공격이 빨라집니다 |

## 빌드

무기는 최대 3개까지 장착합니다. 시작 무기는 4개 중에 고릅니다.

| 무기 | 하는 일 | 진화 조건 | 진화 결과 |
|---|---|---|---|
| 펄스 | 주변으로 충격파 | 증폭 코일 5 | **노바** — 두 겹으로 터지고 적을 밀어냄 |
| 볼트 | 가장 가까운 적 자동 사격 | 분열 코어 5 | **산탄 볼트** — 부채꼴 5발, 관통 |
| 오브 | 주위를 도는 궤도체 | 냉각 장치 5 | **톱날 궤도** — 궤도가 넓어지고 회전 급상승 |
| 체인 | 적 사이를 튕기는 번개 | 자기장 5 | **폭풍** — 튕김 대폭 증가, 맞은 적 정지 |

패시브 6종: 가속 장치(이동속도), 냉각 장치(공격간격), 분열 코어(투사체 수), 증폭 코일(범위), 흡수 회로(흡혈), 자기장(획득 범위). 각 5레벨까지.

**한 판에 오르는 레벨은 30 전후인데 찍을 수 있는 강화는 49개입니다.** 다 못 찍기 때문에 무엇을 포기할지가 곧 빌드입니다. 무기 하나에 몰아서 진화를 노릴지, 셋을 고르게 올릴지가 매판 갈립니다.

## 밸런스 기준

봇으로 12판 자동 플레이한 결과를 기준으로 잡았습니다.

- 클리어율 5/12, 생존 중간값 273초
- 죽는 판은 대부분 60~120초 구간(빌드가 자리잡기 전) 또는 보스전
- 240초까지 살아남으면 보스전은 20~45초짜리 실제 싸움

레벨업 시 카드 3장 중 최소 1장은 무기가 나옵니다. 패시브만 3장 뜨면 화력이 못 따라가서 판이 그냥 끝나기 때문입니다.

## 아트

발광 벡터(네온) 스타일. 색은 6개로 고정하고 이미지 파일은 하나도 쓰지 않습니다.

- 시안 = 플레이어와 아군 투사체
- 마젠타 = 일반 적
- 노랑 = 엘리트, 진화, 경험치 바
- 보라 = 보스, 오브
- 빨강 = 적 탄환, 위험

적이 200마리 넘어도 60fps가 유지되도록 발광을 `shadowBlur` 대신 2단 스트로크로 그립니다.

`art-style-test.html`은 아트 스타일을 정할 때 쓴 비교 페이지입니다. 같은 전투 장면을 다크 / 라이트 / 네온 세 가지로 렌더합니다.
